## Delegated decisions

- Navigation labels are Places and Ideas, keeping `/venues` and `/originals`.
  Public headings, filters and back links use those names. Internal editorial
  operations terminology and source/model identifiers retain their meaning.
- Four direct mobile destinations: Home, Places, Events, Activities. More opens
  News, Ideas, Deals, Operations and Profile (Forum only if already enabled).
  This avoids squeezing seven targets into 375px. Active state, keyboard access,
  Escape/return focus and close-on-navigation are retained. Operations moves out
  of the crowded mobile header into More; existing server authorization remains.
- Current location is compact even for the existing fallback/estimate. Change
  location opens the labelled form, focuses search, preserves text/errors on
  reopening and returns focus after selection. No automatic device permission.
  Existing default/estimated label, radius and session-only persistence remain.
- Home offers nearby Places/Events/Activities links before its shorter mobile
  weekend hero. Activities intro is concise; loading/error/coverage states remain.
  Radius/scope controls use two columns on mobile so the long Listings option
  cannot force an extra full-width row; the widening action remains explicit.
- Browser auth is explicitly reused; server cookie clients remain per request.
  The installed SSR library already defaults to singleton in a browser. The
  anonymous News reader now has a separate nonpersistent storage key so it cannot
  compete with auth. No permissions, credentials or account records change.
- Mobile category artwork declares its actual 128px width (144px on desktop).
  Home hero/place cards use closer container-width hints. Aspect wrappers, lazy
  loading, actual hero priority and existing photo rights/attribution are retained.
